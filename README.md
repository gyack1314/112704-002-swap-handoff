# 柜门和配送终端的换电联调

本机联调记录由设备、控制台和现场终端分别产生，均为合成资料。`field-session.json` 保存设备登记和原始消息。记录数组顺序为接收时点、发送方、消息类型和负载。同一接收时点按文件顺序投递。消息中的设备观测时刻可以早于接收时点。

格口质量为克，nearby 是近场扫描到的标签集合。boot 与 seq 说明回报身份，电池 capacity_wh 和 temperature_c 用于判断可用性。离线授权带可用格口和有效时段。

## 联调连接

每个发送方独立使用 TCP。每条消息先传 4 字节网络序无符号长度，再传 UTF-8 JSON 对象。长度不含帧头，上限 1 MiB。设备请求包含 `at`、`actor`、`kind`、`body`，接收端每请求返回一个同格式的 JSON 帧。`disconnect` 由发送工具关闭该发送方连接，不传给接收端。此发送方下一条有效消息开启新连接。`at` 是场景时点，发送工具按顺序传输，不等待场景中的时间间隔。消息类型和负载实例可直接查看现场会话。

## 环境和运行

使用 Python 3.11 标准库。执行 `python field_client.py --check` 检查会话是否可读。执行 `python -m unittest discover -s tests -v` 会建立临时本地回环连接验证消息、帧及连接。启动接收端后，可用 `python field_client.py --host 127.0.0.1 --port 8765` 发送现场会话，工具逐条打印对端响应。测试中的回环端仅回显真实收取的消息。
